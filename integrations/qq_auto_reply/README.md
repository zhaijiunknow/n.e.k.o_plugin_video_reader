# QQ 集成视频兼容补丁（可选，待端到端验证）

此目录记录与 video_reader v0.3.0 配套的 QQ 侧改动，不会随视频插件安装自动应用。
目标基线为本机 QQ 集成 0.14.13；版本号相同也不保证源码相同，具体原文件 SHA-256 见 baseline-sha256.json。
该文件中 null 表示原本不存在的新文件。补丁不含账号、密钥、群号或运行时配置。

## 应用方式

1. 找到实际运行的 QQ 插件目录（Steam 安装目录与源码目录可能不同），先停用 QQ 插件并备份。
2. 核对基线；在 QQ 插件目录执行 `git apply --check <此目录的绝对路径>/video-integration.patch`。
3. 检查通过后执行 `git apply <此目录的绝对路径>/video-integration.patch`，然后重新启用 QQ 插件。
4. 若基线不匹配或检查失败，请人工合并，不要强制覆盖。已经安装该补丁的用户无需重复应用。
5. 保留原 QQ 工具白名单和管理员权限，明确授权 video_reader 后才可使用。不要为了测试开放所有人的权限。

补丁只允许 prepare_for_qq 视频入口，通过宿主 vision 配置单独分析画面，返回文字给原 QQ 会话；
不调用桌面推送、不修改普通图片/表情包模型路由、不修改主 QQ 会话模型、不修改权限设置。
每轮最多一次视频调用，抽帧最多等待 300 秒，视觉分析最多 65 秒，取消或权限撤销不补发。

## 验证边界

- QQ 桥接、权限撤销、图片校验、取消、超时与回复缓冲等选定回归测试已在本机通过。
- Steam 实机已验证完整 131.23 秒视频的抽帧；没有向真实 QQ 联系人发送自动测试消息。
- 真实 QQ 日志曾出现挂载成功但模型未调用视频工具，随后模型服务 403/AccountOverdueError。
  因此尚不能认定 QQ 端到端已跑通；本补丁不修复上游服务额度/账户错误，也不强制模型调用工具。
- 仅分析画面，不支持声音转写；失败不得凭标题编造内容。
